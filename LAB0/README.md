# Laboratorio 0 — Fundamentos de C++, arreglos y matrices

## Problemas y actividades

### La matriz de números

Sumar los valores de una matriz de múltiplos y obtener el resultado módulo 1 000 000 007.

### El profesor universitario

Contar las notas de A a F por profesor y calcular los totales generales.

### El concurso canino

Seleccionar hasta tres perros que maximicen el producto de su capacidad de arreo.

### Observando aves

Contar aves distintas visibles desde puntos de observación y sus casillas vecinas.

### Números pentagonales

Encontrar el número pentagonal más cercano a cada consulta.

### Hileras binarias

Contar cadenas con cantidades primas de ceros y unos para intervalos de longitudes.
