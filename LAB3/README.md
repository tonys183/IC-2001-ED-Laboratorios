# Laboratorio 3 — Tries y búsqueda por prefijos

## Problemas y actividades

### Las profesiones en los currículums

Reconocer profesiones equivalentes mediante prefijos no ambiguos, sin contar duplicados.

### Los substrings telefónicos

Contar relaciones en las que un número telefónico registrado es prefijo de otro.

### La imprenta

Minimizar inserciones, eliminaciones e impresiones para producir un conjunto de palabras.
