# Laboratorio 2 — Conjuntos, árboles AVL y hashing

## Problemas y actividades

### Clase SET

Implementar conjuntos de cadenas sin duplicados mediante AVL y doble hash, incluyendo unión e intersección.

### Palabras inusuales

Encontrar palabras que aparecen una sola vez en una publicación y no aparecen en la otra, en orden alfabético.
