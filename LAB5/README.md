# Laboratorio 5 — Grafos no ponderados y conectividad

## Problemas y actividades

### Los amigos de mis amigos

Identificar fraternidades como grupos conectados y contar personas aisladas.

### Las caras del polígono

Contar los lados de una figura representada en una matriz, incluyendo sus bordes.

### La persecución de Link

Determinar el recorrido máximo sin reutilizar los lugares que quedan bloqueados.

### El tráfico de red

Obtener distancias mínimas desde una computadora y agrupar destinos según su distancia o falta de conexión.

### El tráfico de red II

Encontrar la mayor distancia mínima entre dos computadoras de una red conectada.
