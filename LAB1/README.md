# Laboratorio 1 — Listas enlazadas

## Problemas y actividades

### Lista simplemente enlazada (SLL)

Implementar inserciones, eliminación, recorrido, barajado y ordenamientos.

### Lista doblemente enlazada (DLL)

Administrar enlaces en ambas direcciones, concatenar listas, obtener extremos y ordenar.

### Lista doblemente enlazada circular (CDLL)

Implementar operaciones de una lista circular y generar sus permutaciones.
